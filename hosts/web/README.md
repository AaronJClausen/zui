# zui-web

A web host and renderer for [zui](https://github.com/AaronJClausen/zui): a canvas surface in the browser.

Built by ROADMAP.md items V4 (the demo in a browser, a thin client over zui_wire) and H5 (the web host).

## Status

Empty: this repository is created ahead of its roadmap items, which fill it in.
See [zui's ROADMAP.md](https://github.com/AaronJClausen/zui/blob/main/ROADMAP.md).
